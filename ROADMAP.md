# Roadmap

Contour is actively developed. The repository tracks planned and in-progress work through
[GitHub issues](https://github.com/dev-marshmallow/contour/issues), including:

- Expand terminal protocol and conformance coverage across the VT, Sixel, kitty, and ReGIS implementations.
- Improve persistent-session reliability, live upgrade, remote access, and tmux interoperability.
- Extend keyboard-driven workflows, command blocks, layouts, accessibility, and QML frontend polish.
- Improve packaging and installation across Linux distributions, macOS, Windows, and BSD systems.
- Grow automated test coverage, benchmarks, fuzzing, diagnostics, and documentation.

For implementation status and concrete next steps, refer to open and recently merged GitHub issues and pull requests.
